# INDF Stock Analytics & Risk Dashboard

## File GitHub
Upload file berikut ke root repository:
- `app.py`
- `Data Indofood.json`
- `requirements.txt`

## Deploy Streamlit Community Cloud
1. Push semua file ke GitHub.
2. Buka Streamlit Community Cloud.
3. Pilih repository dan branch `main`.
4. Main file path: `app.py`.
5. Deploy.

Dashboard berisi harga historis, MA20/MA60, return, rolling volatility,
forecast ARIMA(1,1,1), interval prediksi 95%, Historical VaR 95%/99%,
maximum drawdown, executive insight, dan download data terfilter.
